# Gipfel UI 与功能复核报告（2026-08-14）

## 专业评价

当前界面已经形成一致的机构级桌面工作台语言：深海军蓝承担信息底色，金色只用于主动作、选中态和关键数值；导航、命令栏、内容表面和状态栏层级明确。登录页的静默品牌仪器比原先的宣传文案更适合业务软件，连续运动频率克制，并提供减少动态效果兼容。

本轮复核前的主要短板不在“颜色不高级”，而在细节完成度：部分鼠标点击元素缺少键盘语义、图标按钮没有可读名称、合同驳回存在前后端通道断链、辅助跳转链接缺少离屏样式并参与了主布局。上述问题均已修复。

|---|---|---|

| 无障碍 | 良好 | 跳转链接、可见焦点、按钮名称、标签页关系和键盘操作已补齐 |

## 本轮确认并修复的问题

1. 合同“驳回”调用未注册的 `CONTRACT_REJECT` 通道，改为已注册的 `CONTRACT_APPROVE + reject` 动作。
2. 驳回后的前端临时状态错误写入 `status=rejected`，改为 `approval_status=rejected`，与后端状态机一致。
3. 数据库已升级到 26 个迁移，但本地验收仍断言 25，造成两项误报失败；已统一到 26。
4. `npm run verify` 写死依赖 bash，在 Windows 无法可靠运行；已改为跨平台 Node 调度入口。
5. 云端部分跳过时退出码仍为成功，汇总误显示 PASS；现会明确显示 SKIP。
6. “跳到主要内容”链接没有样式，既可见又作为 Flex 子项挤压整个应用；现仅在键盘聚焦时显示且脱离布局。
7. 通知项、仪表盘最近活动、区域卡片、账户退出区等使用非原生点击容器；已替换为按钮。
8. 合同、区域、公司、公告的图标操作补充可读名称和提示。
9. 股票搜索、行情范围切换和持仓/成交标签页补充可访问名称、选中状态与标签页关联。
10. 公告加载失败原先可能形成未处理异常；现提供明确中文错误提示。

## 后续低风险技术债

- 业务服务仍有 Python/SQLAlchemy 弃用警告，应单独安排依赖升级，避免与本轮 UI/业务修复混合。
- 打包配置仍提示 `asar: false` 和旧版签名字段；当前不影响安装和运行，但应在确认 sql.js/资源加载策略后进行打包加固。
- 云端 `/admin/accounts` 正向管理密钥检查需要在安全环境提供 `GIPFEL_ADMIN_KEY` 后补跑；错误密钥拒绝路径已通过。
