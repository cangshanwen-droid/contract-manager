### 全局层观察（跨页）

- **导航一致性（优）**：侧栏三分组+金色 Active 条+面包屑+折叠+全局搜索 Ctrl+K+通知铃铛，各页标题/只读 Tag/页脚模式统一，IA 成熟度明显高于平均线。
- **信息架构（良）**：路由层级清晰；但存在**死路由**（`/gipfel` 无菜单入口）、rep 可见的跳转目标（/regions）被权限拦截的**可见不可达**矛盾。
- **状态可见性（中）**：骨架屏覆盖 12 页中的 10 页，但 ContractListPage 表格漏 loading；StockMarketPage 行情无「更新于」时间戳；多处网络降级为静默。

## 轮 3：用户研究员 - 三角色体验模拟

### 👤 角色 A：rep（代表端，只读）

**登录后前 5 分钟：**
1. **0:00-0:30** 登录（若 admin 为其创建了 6 位密码 → **直接被「密码至少8位」拦截，卡死在此**。P0-1）
2. **0:30-1:30** 进入仪表盘：看到「欢迎回来」卡（本公司名/已上市股票数/公司总数）+ 8 张 KPI + 最新公告 ✅ 信息对路
3. **1:30-2:30** 点一张区域卡片想看细节 → **跳转 /regions 被 403 拦截** ⚠️（P0-2）；退而点「查看全部合同 →」进入合同总览（只读 Tag 清晰）✅ 可看状态/详情/版本历史
4. **2:30-4:00** 进入股票市场：本公司股票金色边框高亮 + 「本公司」Tag + 图例说明 ✅ **体验亮点**；价格 30s 刷新但无时间戳（P1-12）
5. **4:00-5:00** 资金总览：可看余额与流水；但流水弹窗内出现可输入却无法提交的添加表单（P1-5）⚠️

**核心任务完成度：**
- ✅ 查看本公司股票行情、合同状态、资金概况 - 全部可完成
- ❌ 点区域卡片查看区域详情 - **被 403 阻断**（页面在欢迎语中写着「如需操作请联系操作端」，但点击行为本身没做只读降级）
- 结论：**rep 体验 7/10**。信息供给充分，但「可见不可达」与「创建者给的密码登不上」是两个真实阻断。

### 👤 角色 B：operator（操作员，日活主力）

**登录后前 5 分钟：**
1. **0:00-0:40** 登录 → 仪表盘第一屏就是**待办工作台**（待审批/执行中/已过期计数卡）✅ 定位精准
2. **0:40-2:00** 点「待审批合同」→ 自动跳到合同列表并过滤待审批 ✅ 无缝；批准/驳回按钮就在状态列内，但 5 个按钮挤在 230px 内、绿红相邻（P1-4）⚠️；点批准有 Popconfirm 说明「批准后计入资金流水」✅ 风险提示到位
3. **2:00-3:30** 新建合同：Ctrl+N → 弹窗自动聚焦合同名 → 选类型后按类型渲染专属字段（基建/投资/拨款等 8 套模板）✅ **亮点**；填完保存 → toast「创建成功（草稿，请提交审批）」+ 表单重置可连续录入 ✅
4. **3:30-4:30** 想改刚才合同的金额明细 → 编辑弹窗只有名称+备注 ⚠️（P1-3）只能删了重建
5. **4:30-5:00** 进股票交易 → iframe 加载云端工作台；**云端不通则整页只剩错误态+重试**（P0-3）⚠️

**核心任务完成度：**
- ✅ 审批合同、新建合同（8 类型模板）、记账流水、发公告 - 全部可完成
- ⚠️ 股票交易 - 依赖云端，可用性取决于外网
- ❌ 编辑合同明细 - 不可行（需删除重建）
- 结论：**operator 体验 8/10**。待办工作台→筛选联动、分类型合同模板是明显亮点；编辑能力缺失与 iframe 依赖是主要槽点。

### 👤 角色 C：admin（管理员）

**登录后前 5 分钟：**
1. **0:00-0:30** 登录 → 仪表盘多出「系统概览」区（用户构成/活跃度/今日登录/最近创建用户）✅ 治理视角到位
2. **0:30-1:30** 用户管理：创建操作员/代表账号 - 密码规则 min6+字母数字 ✅；**但创建出的账号在登录页登不进去（min 8）** ⚠️（P0-1）；无密码重置，下属忘密码只能删除重建（P2-7）
3. **1:30-3:00** 账户监控：4 个 Tab（股票账户/系统用户/资金账户/合同概览）+ 审计日志 + 30s 自动刷新 + 详情抽屉 ✅ **亮点**；若云端故障 → 每 30s 一个 error toast（P1-6）⚠️
4. **3:00-4:00** 公告管理：发布/删除/优先级 ✅；但发布者字段可手改（P1-9）⚠️
5. **4:00-5:00** 系统设置：一键备份到桌面 ✅、恢复有覆盖确认 ✅、健康检查显示三项状态点+延迟 ✅；切云端模式后提示「请刷新页面生效」（P1-10）⚠️

**核心任务完成度：**
- ✅ 建用户、全系统监控、备份/恢复、发公告 - 全部可完成
- ❌ 给下属设一个能登录的密码 - **被 P0-1 破坏**
- 结论：**admin 体验 8/10**。监控与数据管理完备，但用户生命周期管理（创建→登录→重置）存在规则断层。

## 三视角交叉结论（共识交集）

| 共识问题 | 三视角共同指向 | 优先级 |
|---------|--------------|--------|
| 密码规则冲突（6 vs 8 位） | 交互设计（P0-1）+ rep/admin 体验均卡死 | **P0 第一修复** |
| rep 点击区域卡片 403 | UX 总监（IA 矛盾）+ rep 模拟（核心路径断裂） | **P0 第二修复** |
| 股票交易 iframe 单点依赖 | 交互设计（P0-3）+ operator 模拟（核心任务不可用） | P0/架构决策 |
| 合同编辑能力不足（明细不可改） | 交互设计（P1-3）+ operator 模拟（重建成本高） | P1 |
| 表格首载假空状态（缺 loading） | UX 总监（状态可见性）+ 交互设计（P1-1） | P1 |
| 云端故障反馈过载/静默并存 | 交互设计（P1-6/7）+ admin 模拟（toast 轰炸） | P1 |

**修复顺序建议**：P0-1（一行改规则）→ P0-2（rep 点击降级为只读弹窗或隐藏 CTA）→ P1-1（加 loading）→ P1-3（编辑放开明细）→ 其余按迭代排期。
